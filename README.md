# 波形实验室

中文电力电子波形教学网站，使用原生 HTML、CSS、JavaScript，无第三方运行依赖。

## 功能

| 实验 | 电路 |
| --- | --- |
| 可控整流 | 单相半波、单相全控桥、单相半控桥、三相半波、三相全控桥 |
| 有源逆变 | 单相全控桥、三相半波、三相全控桥 |

- 支持 R、RL、RLE 负载，调节触发角 α、输入有效值 U₂、R、L、E、频率和触发脉冲宽度。
- 有源逆变实验提供交流侧电感、换相重叠及换相失败示例。
- 相电压、晶闸管电流、触发脉冲、角度读数及主电路导通路径联动。
- 支持时间轴播放、拖动观察、角度/时间横轴切换和 PNG 波形导出。
- 参数形成连续稳定的有源逆变时，自动进入对应实验，并保留电路与参数。
- 响应式布局，可使用手机或电脑浏览器。

## 本地运行

在项目目录执行：

```bash
python -m http.server 8000 --directory dist
```

浏览器打开 `http://localhost:8000`。源码采用 JavaScript 模块，需要通过 HTTP 服务打开。

可控整流首页为 `dist/index.html`；独立有源逆变页为 `dist/inverter.html`。`dist/inverter-ideal.html` 保留 L=0 的理想逆变求解。

## 校验

需要 Node.js，无需安装第三方包：

```bash
npm test
```

当前开发分支 84 项模型与交互校验通过，涵盖平均电压、功率方向、KCL、电感能量、换相极限、失败事件、参数传递与交互回归。DOM 校验不替代真实浏览器布局、触摸和软键盘测试；尚未完成真实 iPhone 验证。

## 模型与教材符号

- 理想器件、三相平衡，三相的 U₂ 为相电压有效值，线电压有效值为 √3U₂。
- RLE 采用串联 R、L、恒定电动势 E；E>0 阻碍正向负载电流，E<0 沿正向电流方向供电。
- 有限负载电感通过电感方程与电流过零事件求解。断流时 RLE 的负载端电压为 E，电流为零。
- 采用王兆安、刘进军《电力电子技术》常见约定：α 为触发角，β=180°−α 为逆变角，γ 为换相重叠角，β−γ 为可用反向电压区间。
- 整流页忽略交流侧电感；独立逆变页可调整交流侧电感并观察重叠与失败。
- “极大电感”使用 L=50 H 的有限电感近似，可切换为自定义电感。
- 模型未加入晶闸管非零恢复时间、磁饱和或实际保护器动作。未达到周期稳态、换相失败或理想支路电流分配不唯一时，页面会明确标注或留空。

## 电压型与电流型逆变（2026-10-12 开发分支更新）

入口为 `dist/dc-inverter.html`，也可以从整流页或有源逆变页进入。

- 单相半桥电压型（图 4-6）。
- 单相全桥电压型，输出脉宽 θ 在 0°～180° 连续可调，180° 时为方波。
- 单相全桥移相调压（图 4-7），输出脉宽 θ 可调。
- 三相桥式电压型（图 4-9、4-10），显示极点、中性点、相、线电压与三相电流。
- 单相并联谐振电流型（图 4-12、4-13），显示换流区、实测反压角和关断时间比较。
- 三相串联二极管式电流型（图 4-14、4-15），显示 120° 电流序列和有限 γ 换流。

支持参数调节、导通器件联动、驱动信号、观察时刻、波形 PNG、参数链接和主电路放大。

电压型采用理想器件和周期稳态 R/RL 电流。电流型按给定 γ 线性交接，是教学近似；换流电容充放电、晶闸管恢复未动态求解。单相电流型在反压不足时显示指定驱动的参考波形，不能当作实际失败后的波形。

`v0.1-beta` 标签和 Release 保留原版快照；以上新增功能在 `main` 分支。


公式使用原生 MathML 显示下标、分数与根号。全桥输出脉宽 θ、晶闸管触发脉宽 δ 支持小数输入及滑块联动，修改后实时更新波形与参数链接。
